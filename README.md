# AI Based Heavy Vehicle Risk Prediction & Safety Recommendation System


##Project link: https://ai-based-vehicle-safety-recommendation-system-fyqzwmmkhijaagzw.streamlit.app/


## Project Overview

The AI Based Heavy Vehicle Risk Prediction & Safety Recommendation System is a Machine Learning-based project designed to assess the safety risk of heavy vehicle journeys.

The system analyses different factors related to the driver and vehicle, such as driving hours, speed, drowsiness score, harsh braking, engine temperature, tyre pressure, vehicle age and previous safety history.

Based on these factors, the system assesses the risk level and provides preventive safety recommendations.

> Note: This system provides risk assessment based on available input data. It does not guarantee or directly predict an actual accident.

## Features

- Driver safety risk prediction
- Vehicle breakdown risk prediction
- Analysis of driver and vehicle-related factors
- Exploratory Data Analysis (EDA)
- Feature importance analysis
- Machine Learning model evaluation
- Safety recommendations based on identified risk factors
- Streamlit-based web application
